# feature-tabs Specification

## Purpose
Features 섹션의 세 기능 소개를 탭으로 전환할 때, 보조 기술 사용자에게 탭 구조와 선택 상태를 알리고 키보드만으로 탭을 고르고 패널 내용에 도달할 수 있도록 동작을 정의한다.

## Requirements

### Requirement: 탭 의미 제공

Features 전환기는 SHALL "Features"라는 이름의 탭 목록과 그 안의 세 탭으로 노출되고, 각 탭은 자신이 표시하는 패널을 제어하며 각 패널은 해당 탭 이름을 가진 탭 패널로 노출된다. 전환기는 내비게이션 랜드마크로 노출되지 않는다.

#### Scenario: 보조 기술에 노출되는 구조

- **WHEN** 화면 읽기로 Features 섹션을 탐색한다.
- **THEN** "Features" 탭 목록과 Simple Bookmarking, Speedy Searching, Easy Sharing 탭이 순서와 개수(3개 중 N번째)와 함께 안내된다.
- **THEN** 표시 중인 패널은 선택된 탭의 이름을 가진 탭 패널로 안내된다.

#### Scenario: 랜드마크 목록

- **WHEN** 화면 읽기로 페이지의 랜드마크 목록을 연다.
- **THEN** "Features" 내비게이션 랜드마크는 나타나지 않는다.

### Requirement: 선택 상태 안내

시스템은 SHALL 항상 정확히 하나의 탭을 선택 상태로 두고, 선택된 탭의 패널만 표시하며, 선택이 바뀌면 보조 기술이 새 선택 상태를 안내할 수 있도록 선택 상태를 갱신한다.

#### Scenario: 초기 상태

- **WHEN** 페이지를 연다.
- **THEN** Simple Bookmarking 탭이 선택되어 있고 해당 패널만 표시되며 선택 밑줄이 그 탭에 있다.

#### Scenario: 클릭이나 Enter·Space로 선택

- **WHEN** 선택되지 않은 탭을 클릭하거나 포커스한 뒤 Enter 또는 Space를 누른다.
- **THEN** 그 탭이 선택 상태가 되고 그 패널만 표시되며 이전 탭은 선택 해제된다.
- **THEN** 포커스는 활성화한 탭에 있고 화면 읽기는 선택됨 상태를 안내한다.
- **THEN** 페이지 스크롤 위치와 주소의 해시는 바뀌지 않는다.

### Requirement: 키보드 탭 이동

탭 목록은 SHALL Tab 순서에서 선택된 탭 하나에만 멈추고, 탭 목록 안에서 화살표 키와 Home/End로 탭 사이를 이동하며, 이동한 탭을 즉시 선택한다.

#### Scenario: 화살표 키 이동

- **WHEN** 탭에 포커스한 상태에서 오른쪽 또는 아래쪽 화살표를 누른다.
- **THEN** 다음 탭으로 포커스가 이동하며 그 탭이 선택되고 패널이 바뀐다. 마지막 탭에서는 첫 탭으로 순환한다.
- **WHEN** 왼쪽 또는 위쪽 화살표를 누른다.
- **THEN** 이전 탭으로 같은 방식으로 이동하며 첫 탭에서는 마지막 탭으로 순환한다.

#### Scenario: Home과 End

- **WHEN** 탭에 포커스한 상태에서 Home 또는 End를 누른다.
- **THEN** 첫 번째 또는 마지막 탭으로 포커스가 이동하며 그 탭이 선택된다.

#### Scenario: 탭 목록에서 패널로 이동

- **WHEN** 선택된 탭에서 Tab을 누른다.
- **THEN** 다른 탭을 거치지 않고 표시 중인 패널의 첫 포커스 가능 요소(More Info 링크)로 이동한다.
- **WHEN** 패널에서 Shift+Tab으로 탭 목록에 돌아온다.
- **THEN** 포커스는 선택된 탭에 위치한다.
