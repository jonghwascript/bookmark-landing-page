# Proposal

## Why

375px 화면(모바일 디자인 기준 폭)에서 히어로의 Get it on Chrome, Get it on Firefox 버튼이 모바일 디자인과 달리 두 줄로 쌓인다. 버튼 줄의 가용 폭은 313px인데 두 버튼과 간격의 합이 315.8px(152.4 + 16 + 147.4)로 2.8px 넘쳐 `flex-wrap`이 줄바꿈을 일으킨다. 디자인에서는 두 버튼이 약 147px, 142px 폭으로 한 줄에 놓여 있어 현재 버튼의 좌우 여백이 디자인보다 넓다.

## What Changes

- 모바일 폭에서 두 다운로드 버튼의 좌우 여백을 줄여 375px 화면에서 한 줄에 나란히 놓이게 한다.
- 태블릿·데스크톱(md 이상)의 버튼 여백과 모양은 현재 값을 유지한다.
- 두 버튼이 한 줄에 들어가지 않는 더 좁은 화면(예: 320px)에서는 지금처럼 줄바꿈해 가로 넘침 없이 표시한다.
- 버튼 글자, 색, 높이, 호버 상태, 링크 목적지는 바꾸지 않는다.

## Capabilities

### New Capabilities

없음.

### Modified Capabilities

- `hero-content`: 다운로드 버튼의 모바일 배치 요구(375px 이상에서 한 줄, 더 좁으면 넘침 없이 줄바꿈)를 추가한다.

## Impact

- `index.html`: 히어로 다운로드 버튼 두 개의 좌우 여백 클래스.
- CSS 파일, 스크립트, 다른 섹션은 변경 없음.
