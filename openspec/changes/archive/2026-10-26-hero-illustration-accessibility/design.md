# Design

## Context

`section[aria-labelledby="hero-title"]` 안의 첫 SVG는 브라우저 화면을 본뜬 장식이다. SVG에는 링크나 입력 컨트롤이 없으며 제품 설명은 인접한 h1과 문단으로 제공한다. 인라인 마크업에는 도형, 필터, 그라디언트와 반응형 클래스가 있다.

## Goals / Non-Goals

**Goals:** 시각적 렌더링을 유지하면서 SVG 하위 트리를 보조 기술 탐색에서 제외한다.

**Non-Goals:** 다른 SVG의 접근성 변경, 이미지 파일 추출, 레이아웃 재설계, 제품 설명 추가.

## Decisions

- 인라인 SVG 루트에 `aria-hidden="true"`를 지정한다. 인접한 텍스트 외의 추가 정보가 없으므로 접근 가능한 이름을 추가하면 불필요한 설명이 된다.
- `focusable="false"`를 함께 지정하고 tabindex를 추가하지 않는다. SVG 내부에도 포커스 가능한 요소를 추가하지 않는다.
- 외부 SVG 파일을 img와 빈 alt로 불러오는 방식도 가능하지만 파일 분리 없이 속성만 추가하는 방식을 선택한다. 기존 필터와 크기·배치를 유지하기 쉽다.
- Chrome 접근성 트리와 키보드 탐색으로 장식 제외 및 기존 콘텐츠 유지를 검증한다. 이 결과를 실제 화면 읽기 음성 검증으로 표현하지 않는다.

## Risks / Trade-offs

- 숨김 범위가 텍스트까지 확장됨 → 속성은 SVG 루트에만 적용하고 제목·문단·링크의 접근성 노출을 확인한다.
- 향후 SVG에 의미 있는 정보가 추가됨 → 장식 여부를 다시 판단하고, 정보 이미지라면 숨김을 제거한 뒤 간결한 이름을 제공한다.
