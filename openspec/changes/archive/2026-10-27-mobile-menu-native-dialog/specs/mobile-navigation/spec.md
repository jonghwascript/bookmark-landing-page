# Spec Delta

## MODIFIED Requirements

### Requirement: 메뉴 내부 포커스 유지

열린 메뉴는 SHALL 키보드 포커스가 메뉴 밖의 페이지 콘텐츠로 이동하지 않게 하고, 메뉴 안에서는 현재 표시된 활성 컨트롤 사이를 문서 순서대로 양방향 이동하게 한다. 메뉴의 처음이나 끝을 넘어선 이동은 브라우저 기본 모달 동작에 따라 메뉴 안에서 순환하거나 브라우저 UI로 나갈 수 있지만, 뒤쪽 페이지 요소에는 도달하지 않는다.

#### Scenario: 마지막 컨트롤에서 전진

- **WHEN** 열린 메뉴의 마지막 포커스 가능 요소에서 Tab을 누른다.
- **THEN** 포커스는 뒤쪽 히어로 영역이나 다른 페이지 콘텐츠로 이동하지 않는다.
- **THEN** 다시 페이지로 돌아온 포커스는 메뉴 안의 컨트롤에 위치한다.

#### Scenario: 첫 컨트롤에서 후진

- **WHEN** 열린 메뉴의 첫 번째 포커스 가능 요소에서 Shift+Tab을 누른다.
- **THEN** 포커스는 메뉴 아래에 깔린 햄버거 트리거나 다른 헤더 요소로 이동하지 않는다.
- **THEN** 다시 페이지로 돌아온 포커스는 메뉴 안의 컨트롤에 위치한다.

#### Scenario: 외부 포커스 이동

- **WHEN** 열린 메뉴 밖으로 포커스 이동이 시도된다.
- **THEN** 포커스는 메뉴 내부에 유지된다.

### Requirement: 배경 접근 제한과 복원

메뉴가 열린 동안 시스템은 SHALL 메뉴 밖 콘텐츠의 키보드, 포인터 및 화면 읽기 접근을 차단하고 닫힌 뒤에는 열기 전 접근 상태를 복원한다.

#### Scenario: 배경 탐색 차단

- **WHEN** 열린 메뉴에서 키보드나 화면 읽기 탐색으로 배경 콘텐츠에 접근한다.
- **THEN** 배경 콘텐츠는 포커스되거나 탐색되지 않는다.

#### Scenario: 화면 읽기 가상 커서 제한

- **WHEN** 메뉴가 열린 상태에서 화면 읽기의 가상 커서나 훑기 탐색으로 메뉴 끝을 지나 계속 읽는다.
- **THEN** 메뉴 뒤쪽 페이지의 제목, 본문, 링크는 읽히지 않는다.

#### Scenario: 기존 배경 상태 보존

- **WHEN** 메뉴를 열었다가 닫는다.
- **THEN** 배경은 열기 전의 접근 상태로 복원되고 원래 비활성인 요소는 비활성 상태를 유지한다.
