# Spec Delta

## ADDED Requirements

### Requirement: 배경 스크롤 고정

모바일 메뉴가 열린 동안 시스템은 SHALL 메뉴 뒤 페이지의 스크롤 위치를 고정하고, 메뉴가 닫히면 열기 전 위치에서 다시 스크롤할 수 있게 한다.

#### Scenario: 열린 메뉴 위에서 스크롤

- **WHEN** 메뉴가 열린 상태에서 메뉴 위로 마우스 휠이나 터치로 스크롤한다.
- **THEN** 메뉴 뒤 페이지의 스크롤 위치는 바뀌지 않는다.

#### Scenario: 메뉴 닫은 뒤

- **WHEN** 메뉴를 닫는다.
- **THEN** 페이지 스크롤 위치는 메뉴를 열기 전과 같고 이후 다시 스크롤할 수 있다.

#### Scenario: 메뉴 내용이 화면보다 길 때

- **WHEN** 화면 높이가 메뉴 내용보다 낮은 상태에서 열린 메뉴를 스크롤한다.
- **THEN** 메뉴 내용이 스크롤되어 아래쪽 항목에 도달할 수 있고 배경 페이지는 움직이지 않는다.
