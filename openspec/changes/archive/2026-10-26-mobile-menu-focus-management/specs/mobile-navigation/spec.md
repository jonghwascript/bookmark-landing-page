# Spec Delta

## Purpose

전체 화면 모바일 내비게이션을 키보드와 화면 읽기로 안전하게 탐색할 수 있도록 메뉴의 모달 의미, 포커스 이동과 순환, 배경 접근 제한 및 종료 후 복원 동작을 정의한다.

## ADDED Requirements

### Requirement: 메뉴 열기와 초기 포커스

메뉴는 SHALL 접근 가능한 이름을 가진 모달 대화상자로 제공되고, 열릴 때 닫기 컨트롤로 포커스를 이동하며 트리거의 펼침 상태를 표시한다.

#### Scenario: 트리거로 메뉴 열기

- **WHEN** 모바일 메뉴 트리거를 활성화한다.
- **THEN** 메뉴가 표시되고 닫기 컨트롤에 포커스가 있으며 트리거의 aria-expanded는 true다.
- **THEN** 화면 읽기에 메뉴의 이름과 모달 대화상자 의미가 제공된다.

### Requirement: 메뉴 내부 포커스 유지

열린 메뉴는 SHALL 키보드 포커스를 내부에 유지하고 현재 표시된 활성 컨트롤 사이에서 양방향으로 순환시킨다.

#### Scenario: 마지막 컨트롤에서 전진

- **WHEN** 마지막 포커스 가능 요소에서 Tab을 누른다.
- **THEN** 첫 번째 포커스 가능 요소로 이동한다.

#### Scenario: 첫 컨트롤에서 후진

- **WHEN** 첫 번째 포커스 가능 요소에서 Shift+Tab을 누른다.
- **THEN** 마지막 포커스 가능 요소로 이동한다.

#### Scenario: 외부 포커스 이동

- **WHEN** 열린 메뉴 밖으로 포커스 이동이 시도된다.
- **THEN** 포커스는 메뉴 내부에 유지된다.

### Requirement: 배경 접근 제한과 복원

메뉴가 열린 동안 시스템은 SHALL 메뉴 밖 콘텐츠의 키보드 및 화면 읽기 접근을 차단하고 닫힌 뒤에는 열기 전 접근 상태를 복원한다.

#### Scenario: 배경 탐색 차단

- **WHEN** 열린 메뉴에서 키보드나 화면 읽기 탐색으로 배경 콘텐츠에 접근한다.
- **THEN** 배경 콘텐츠는 포커스되거나 탐색되지 않는다.

#### Scenario: 기존 배경 상태 보존

- **WHEN** 메뉴를 열었다가 닫는다.
- **THEN** 배경은 열기 전의 접근 상태로 복원되고 원래 비활성인 요소는 비활성 상태를 유지한다.

### Requirement: 메뉴 닫기와 포커스 복귀

모바일 메뉴는 SHALL 닫기 컨트롤, Escape 또는 메뉴 링크 선택으로 닫히고, 트리거로 포커스를 돌려주며 펼침 상태를 해제한다.

#### Scenario: 닫기 컨트롤 또는 Escape 사용

- **WHEN** 열린 메뉴에서 닫기 컨트롤을 활성화하거나 Escape를 누른다.
- **THEN** 메뉴가 숨겨지고 트리거에 포커스가 있으며 aria-expanded는 false다.

#### Scenario: 페이지 내부 링크 선택

- **WHEN** 메뉴의 페이지 내부 링크를 선택한다.
- **THEN** 메뉴가 닫히고 트리거로 포커스가 복귀하며 링크의 기본 목적지 이동이 수행된다.

### Requirement: 데스크톱 전환 시 상태 해제

시스템은 SHALL 열린 모바일 메뉴가 데스크톱 화면 폭으로 전환될 때 메뉴를 닫고 배경 접근을 복원하며 표시된 헤더 내비게이션 요소에 포커스를 둔다.

#### Scenario: 열린 상태에서 데스크톱으로 확대

- **WHEN** 메뉴가 열린 상태에서 lg 화면 폭에 진입한다.
- **THEN** 메뉴가 닫히고 배경 접근 차단이 해제되며 포커스는 표시된 헤더 내비게이션 요소에 위치한다.
- **THEN** 다시 모바일 화면 폭으로 돌아와도 메뉴는 닫힌 상태이고 다시 정상적으로 열 수 있다.
