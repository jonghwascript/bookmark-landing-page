# Figma 수치 표 정리 프롬프트

Figma 프레임 링크에서 레이아웃 수치만 뽑아 브레이크포인트별 표로 정리할 때 쓰는 프롬프트입니다. 코드는 바꾸지 않습니다.

## 사용법

아래처럼 이 파일을 참조하고 링크를 붙여 넣습니다.

```text
@doc/figma-spec-table.md 대로 정리해줘
- 모바일 : https://www.figma.com/design/TzYYUJSgBicmEJYKyFIoEb/bookmark-landing-page?node-id=8063-2&m=dev
- 태블릿 : https://www.figma.com/design/TzYYUJSgBicmEJYKyFIoEb/bookmark-landing-page?node-id=6040-256&m=dev
- 데스트톱: https://www.figma.com/design/TzYYUJSgBicmEJYKyFIoEb/bookmark-landing-page?node-id=8063-314&m=dev
```

- 링크마다 어떤 화면인지(모바일·태블릿·데스크톱) 적습니다. 적지 않으면 프레임 폭으로 판단합니다.
- 특정 컴포넌트만 필요하면 끝에 적습니다. 예: `통계 카드만`

---

## 프롬프트 본문

아래 지시에 따라 Figma 수치를 표로 정리하세요.

### 1. 수치 읽기

- 링크에서 `fileKey`와 `node-id`를 뽑습니다. `node-id`의 `-`는 `:`로 바꿉니다(`6010-531` → `6010:531`).
- 링크마다 Figma MCP의 `get_metadata`로 레이어 구조, 위치(x, y), 크기(w, h)를 읽습니다.
- 글자 크기·굵기·줄높이·색이 필요하면 `get_design_context`를 추가로 호출합니다. 위치와 크기만이면 `get_metadata`로 충분합니다.
- 권한 오류("don't have edit access")가 나면 멈추고 알립니다. 파일 메뉴의 **Duplicate to your drafts**로 복제한 뒤 복사본 링크를 달라고 안내합니다. 수치를 짐작해서 채우지 않습니다.

### 2. 값 계산 규칙

`get_metadata`는 패딩·간격을 직접 주지 않습니다. 레이어 위치로 계산합니다.

| 구할 값      | 계산                                                  |
| --------- | --------------------------------------------------- |
| 위·왼쪽 패딩   | 첫 자식의 y / x                                         |
| 아래·오른쪽 패딩 | 부모 h − (자식 y + 자식 h) / 부모 w − (자식 x + 자식 w)         |
| 형제 사이 간격  | 다음 형제 y − (이전 형제 y + 이전 형제 h)                       |
| 줄높이       | 텍스트 레이어의 h (한 줄일 때). 여러 줄이면 h ÷ 줄 수                 |
| 그리드 간격    | 다음 카드 x − (이전 카드 x + 이전 카드 w)                       |
| 배치        | 같은 줄 형제의 x와 w로 판단: 같은 폭으로 나눔 / 고정 폭 + 가운데 / 좌우 끝 정렬 |

- 오른쪽 패널 값(오토레이아웃 패딩·간격)과 레이어 위치로 계산한 값이 다르면, **레이어 위치 값을 쓰고** 차이를 따로 적습니다. 패널은 다른 레이어를 선택한 상태일 수 있습니다.
- 같은 종류 요소(카드 6개 등)끼리 값이 다르면 **가장 많은 값**을 표에 쓰고, 다른 값은 "예외"로 적습니다. 예: `6개 중 5개 30px, Work 카드만 32.5px`
- 소수점은 Figma 값 그대로 둡니다(21.5, 25.5). 반올림하지 않습니다.

### 3. 출력 형식

컴포넌트마다 표 하나를 만들고, 열은 브레이크포인트, 행은 항목으로 합니다. 값은 `px (rem)`으로 적고 rem은 16으로 나눈 값입니다.

```markdown
## 통계 카드

| 항목                      | 모바일 (375)                    | 태블릿 (768)   | 데스크톱 (1440) |
| ------------------------- | ------------------------------- | -------------- | --------------- |
| 카드 크기                 | 327 × 160                       | 188 × 213      | 255 × 244       |
| 색 띠 높이                | 38 (2.375rem)                   | 33 (2.0625rem) | 45 (2.8125rem)  |
| 본문 패딩 (위아래 / 좌우) | 27.5 / 24                       | 25.5 / 21.5    | 31 / 30         |
| 제목 줄높이               | 21                              | 21             | 21              |
| 제목 → 숫자 간격          | 8                               | 16             | 24              |
| 숫자 줄높이               | 38                              | 66             | 66              |
| 숫자 → 이전 기간 간격     | 같은 줄                         | 8              | 8               |
| 이전 기간 줄높이          | 18                              | 18             | 18              |
| 본문 높이 합계            | 122 = 27.5 + 21 + 8 + 38 + 27.5 | 180 = …        | 199 = …         |
```

표마다 다음을 지킵니다.

- **높이 합계 행**을 넣고, 패딩·줄높이·간격을 더한 식이 프레임 높이와 맞는지 보여 줍니다. 맞지 않으면 차이를 적습니다.
- 해당 화면에 없는 항목은 `—`, 레이어에서 확인할 수 없는 값은 `확인 필요`로 적습니다. 빈칸으로 두지 않습니다.
- 표 아래에 **예외와 주의 사항**만 목록으로 적습니다. 예: 같은 종류 요소 간 차이, 패널 값과 레이어 값의 차이, 화면마다 구조가 달라지는 부분(가로 → 세로 배치 등).

전체 결과는 다음 순서로 냅니다.

1. **페이지 레이아웃**: 콘텐츠 시작 x, 콘텐츠 폭, 그리드 열 수, 카드 간격(가로·세로)
2. **컴포넌트별 표**: 프레임 안 레이어 이름과 구조를 보고 의미 있는 단위로 나눕니다(예: 리포트 카드, 기간 필터, 통계 카드).
3. **화면마다 달라지는 값 요약**: 세 화면에서 값이 다른 항목만 모은 짧은 목록. CSS 미디어 쿼리에 넣어야 할 값을 한눈에 보기 위한 것입니다.

### 4. 하지 않을 것

- 코드나 파일을 수정하지 않습니다. 수치 정리만 합니다.
- 이미지(JPG·PNG) 측정값을 섞지 않습니다. 이미지 내보내기는 Figma와 몇 px 다를 수 있습니다.
- 레이어에 없는 값을 비율이나 다른 화면 값으로 추정하지 않습니다.
