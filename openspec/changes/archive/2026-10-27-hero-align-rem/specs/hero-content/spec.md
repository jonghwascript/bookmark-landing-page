# Spec Delta

## ADDED Requirements

### Requirement: 데스크톱 히어로 정렬

lg 이상 화면 폭에서 히어로 제목은 SHALL 브라우저 기본 글꼴 크기와 관계없이 헤더 로고와 같은 왼쪽 위치에서 시작한다.

#### Scenario: 기본 글꼴 크기

- **WHEN** 브라우저 기본 글꼴 크기가 16px인 상태에서 1024px 이상 화면으로 페이지를 연다.
- **THEN** 히어로 제목의 왼쪽 위치는 헤더 로고의 왼쪽 위치와 같고, 위치는 변경 전과 같다.

#### Scenario: 키운 기본 글꼴 크기

- **WHEN** 브라우저 기본 글꼴 크기를 20px 또는 24px로 키운 상태에서 1024~1600px 화면으로 페이지를 연다.
- **THEN** 히어로 제목의 왼쪽 위치는 헤더 로고의 왼쪽 위치와 같다.
