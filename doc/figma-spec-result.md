## 화면마다 달라지는 값 요약

- 콘텐츠 시작 x와 폭은 화면 및 섹션에 따라 달라집니다. 모바일의 주요 콘텐츠는 x 32px, 폭 311px입니다.
- 브라우저 카드는 모바일에서 세로 1열·간격 40px, 태블릿에서 가로 3열·간격 8px, 데스크톱에서 가로 3열·간격 32px입니다.
- 히어로는 태블릿에서 이미지 아래 텍스트, 데스크톱에서 가로 배치입니다.
- CTA의 입력란과 버튼은 모바일에서 세로, 태블릿·데스크톱에서 가로 배치입니다.
- FAQ 폭은 모바일 311px, 태블릿·데스크톱 540px입니다.

Figma MCP 호출 한도에 도달해 모바일 심벌 내부와 일부 세부 레이어는 더 읽지 못했습니다. 해당 값은 추정하지 않았습니다.
